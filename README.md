# 💰 MoneyGuard

**MoneyGuard** — це веб‑додаток для контролю особистих фінансів, який допомагає відстежувати баланс, витрати та доходи, а також аналізувати статистику у зручному інтерфейсі.

---

## 🚀 Основні можливості
- 📊 **Статистика**: перегляд графіків та таблиць з фінансовими даними.
- 🏠 **Головна сторінка (Home)**: додавання транзакцій, оновлення балансу.
- 🔐 **Аутентифікація**: реєстрація та логін користувачів.
- 🧾 **Баланс**: відображення поточного стану рахунку.
- 💱 **Курси валют**: блок із прикладом валютних курсів.
- 🎨 **UI/UX**: сучасний дизайн з темною палітрою та адаптивною версткою.

---

## 🛠️ Технології
- **React** — основний фреймворк для побудови інтерфейсу.
- **React Router v6** — маршрутизація та редіректи.
- **Chart.js** — побудова графіків та діаграм на сторінці статистики.
- **CSS Modules** — стилізація компонентів.

## 👤 Авторизація
- Якщо користувач **не залогінений**:  
  - Показуються лише форми **LoginForm** та **RegisterForm**.  
  - Можна зареєструватися або увійти.

- Якщо користувач **залогінений**:  
  - Доступні сторінки **Home** та **Statistics**.  
  - У хедері відображається ім’я користувача та кнопка виходу.  
  - Після виходу користувач повертається на екран логіну.

- Після реєстрації чи логіну користувач автоматично перенаправляється на `/statistics`.

## 🎯 Мета проєкту
MoneyGuard створений для того, щоб навчитися працювати з:
- Маршрутизацією у React (React Router v6).
- Побудовою графіків та діаграм (Chart.js).
- Роботою з локальним сховищем (LocalStorage).
- Модульними стилями (CSS Modules).
- Хуками React (`useState`, `useContext`, `useRef`).

Основна ідея — зробити простий, але функціональний фінансовий трекер з авторизацією та статистикою.

---

## 📈 Приклад роботи
- У боковій панелі (**Sidebar**) відображається баланс користувача та курси валют.
- На сторінці **Home** можна додавати транзакції, які змінюють баланс.
- На сторінці **Statistics** за допомогою **Chart.js** будуються графіки витрат та доходів.
- Після входу користувач автоматично перенаправляється на `/statistics`.
